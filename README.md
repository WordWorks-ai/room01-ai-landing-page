# room01.ai (landing page)

This repository contains a static landing page for **room01.ai** and a platform overview for **room0** at `/room0/`.

- **room01**: message-first client experience + future always-on Mac mini appliance
- **room0**: authority substrate / governance kernel (policy, tool gateway, receipts, contracts)

## Run locally

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy on GitHub Pages

1. Push this repo to GitHub (public repo recommended).
2. Repo → **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: `main`
5. Folder: `/ (root)`
