# WordWorks AI static site (brand pass)

This package is ready to deploy to GitHub Pages or any static host.

## Deploy
1. Unzip the archive.
2. Upload the **contents** of `wordworks-agentic-site/` to the repo root for the site.
3. Keep your existing `CNAME` file if your GitHub Pages repo already uses one.
4. Commit and push.

- `styles.css`
